# Vendored test dependency

`vizi_hostsim/` is the host emulator from vizi-plugin-sdk
(`examples/vizi_hostsim/`), copied unchanged so the emulator tests run without
an SDK checkout.  It is the SDK's, under the Apache License, Version 2.0 (see
`LICENSE` and `NOTICE` at the root of this repository).  It is test-only and
is not part of the plugin's release.
